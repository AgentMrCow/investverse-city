# Investverse City

## Overview
Investverse City is a web-based financial learning game that combines quizzes with city-building.

## Development
Requirements: Node.js and npm.

```sh
# Step 1: Clone the repository using the project's Git URL.
git clone <YOUR_GIT_URL>

# Step 2: Navigate to the project directory.
cd <YOUR_PROJECT_NAME>

# Step 3: Install the necessary dependencies.
npm i

# Step 4: Start the development server with auto-reloading.
npm run dev
```

## Tech Stack
- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS

## Deployment
Run `npm run build` and deploy the output in `dist/` to your preferred hosting platform.
